# JVM

JVM 是运行 Java 字节码的虚拟机。`javac` 把 `.java` 编译成 `.class`，JVM 再执行这些字节码。同一份字节码可以在装了对应 JVM 的不同系统上跑。

## 栈

每个线程有自己的栈。方法被调用时，JVM 在栈上放一帧，里面有局部变量和这次调用的状态。方法返回后，这一帧就丢掉。

```java
int add(int a, int b) {
    int sum = a + b;
    return sum;
}
```

`a`、`b`、`sum` 都在当前方法的栈帧里。栈上的数据随方法结束释放，不需要垃圾回收来管。

## 堆

用 `new` 创建的对象放在堆上。堆由所有线程共享。

```java
User user = new User("小明");
```

局部变量 `user` 在栈上，它保存的是堆里那个 `User` 对象的引用。对象本身在堆上，方法结束后，只要没有别的地方还指着它，就可以被回收。

## GC

GC（垃圾回收）负责找出堆上不再被用到的对象，并释放它们占的内存。你一般不用手动 `free`。

对象从栈上的局部变量、静态字段出发还能被找到，就还活着。找不到的对象会被回收。

频繁创建大量短命对象会让 GC 更忙。集合只增不删、静态集合一直持有对象，会导致内存一直涨。出现 `OutOfMemoryError` 时，先看是不是有对象被意外一直引用着。
